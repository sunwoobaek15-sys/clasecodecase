# IMAGE FACTORY 샘플 3종

모두 코드(SVG)로 직접 그린 오리지널 이미지입니다. 저작권 캐릭터·로고·글자 없음 → 상업적 사용 가능.
SVG는 해상도 손실 없이 확대/수정 가능, PNG는 바로 사용용입니다.

| # | 파일 | 용도 | 크기 |
|---|------|------|------|
| 1 | 01-thumbnail-survival-night | 유튜브 썸네일 (생존/공포 게임) | 1280×720 (16:9) |
| 2 | 02-icon-crystal-sword | 게임/앱 아이콘 (판타지 RPG) | 1024×1024 (1:1, 투명 모서리) |
| 3 | 03-background-floating-isles | 2D 게임 배경 (횡스크롤) | 1920×1080 (16:9) |

## 1. 썸네일 — 밤 숲속 캠프파이어
- 놀란 표정의 생존자를 왼쪽에 크게, 캠프파이어 불빛을 중심 광원으로 배치
- 오른쪽 어둠 속 붉은 눈 → 긴장감 / 클릭 유도
- **오른쪽 위 하늘 영역은 제목 공간으로 비워둠**

AI 생성기용 프롬프트:
```
YouTube thumbnail, survival horror game, hooded survivor with shocked expression on the left,
bright campfire in the center casting warm orange light, dark pine forest at night, full moon,
glowing red eyes hiding in the dark trees on the right, empty dark sky top-right for title text,
high contrast, stylized 3D cartoon, cinematic lighting, sharp focus, 16:9
Negative: text, letters, logo, watermark, extra fingers, distorted face, blurry
```

## 2. 아이콘 — 크리스탈 검
- 대각선 구도로 작은 크기(48px)에서도 실루엣이 명확
- 보라 배경 ↔ 하늘색 칼날 보색 대비, 금색 손잡이 + 분홍 보석 포인트

```
game app icon, glowing crystal sword with golden crossguard and pink gem, diagonal composition,
purple gradient rounded-square background, magical sparkles, cyan glow,
clean vector style, mobile game icon, centered, 1:1
Negative: text, logo, watermark, cluttered background, blurry
```

## 3. 배경 — 노을 속 공중섬
- 원경 산 → 중경 산 → 근경 언덕 → 바닥 4단 레이어 (패럴랙스 스크롤용으로 분리 가능)
- 맨 아래 어두운 띠는 캐릭터가 걷는 바닥 영역

```
2D side-scrolling game background, floating islands with trees and a waterfall, ancient stone ruin
on a small island, sunset sky purple to orange, layered mountains for parallax, flat vector art,
soft gradients, no characters, 16:9, 1920x1080
Negative: text, logo, watermark, characters, noise
```

무료로 쓸 수 있는 생성기 예: Bing Image Creator, Leonardo.ai(무료 플랜), Ideogram.
상업적으로 쓰기 전에 각 서비스의 이용약관을 꼭 확인하세요.
