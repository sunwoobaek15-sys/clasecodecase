# Kiwi & Kimchi Party

**한국 × 뉴질랜드 문화 체험 미니게임 컬렉션**

한국과 뉴질랜드 학생들이 음식, 자연, 전통문화를 짧은 미니게임으로 체험하는 브라우저 게임이에요.
설치 없이 휴대폰, 태블릿, PC 브라우저에서 바로 실행되고, 영어(기본)와 한국어를 지원해요.

## 현재 진행 상황

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| 1단계 | 기본 구조, 메인 메뉴 | ✅ 완료 |
| 2단계 | GAME 01 Kimchi Run 구현 + 테스트 | ✅ 완료 (자동 테스트 95개 통과) |
| 3단계 | GAME 02 Pavlova Dash | ⏳ 아직 안 함 (메뉴에 "Coming soon" 표시) |
| 4단계 | GAME 03 Palace Builder | ⏳ 아직 안 함 |
| 5단계 | GAME 04 Kiwi Forest Rescue | ⏳ 아직 안 함 |
| 6단계 | 네 게임 연결, 공통 UI 정리 | 🔸 공통 UI는 완성, 나머지 게임 연결 대기 |
| 7~8단계 | 온라인 멀티플레이 (방 만들기, 방 코드, 대기실 등) | ⏳ 아직 안 함 |
| 9단계 | 전체 기기 테스트, 배포 준비 | 🔸 Kimchi Run 기준으로 모바일/PC 테스트 완료 |

> 아직 만들지 않은 게임은 메뉴에서 PLAY 버튼 대신 "Coming soon"으로 보여요. 누를 수 있는 가짜 버튼은 없어요.
> 온라인 멀티플레이는 아직 구현되지 않았어요.

## 바로 실행하기

### 방법 1. 파일 더블클릭 (가장 쉬움)

1. 이 폴더(`kiwi-kimchi-party`)를 열어요.
2. `index.html` 파일을 더블클릭하면 브라우저에서 게임이 열려요.

별도 설치나 빌드가 필요 없어요. 인터넷이 없으면 글꼴만 기본 글꼴로 바뀌고 게임은 그대로 동작해요.

### 방법 2. 로컬 서버로 실행 (휴대폰에서 같이 테스트할 때)

[Node.js](https://nodejs.org/) 20 이상이 설치되어 있어야 해요.

```bash
cd kiwi-kimchi-party
npm start
```

브라우저에서 <http://localhost:8080> 을 열어요.
같은 와이파이에 연결된 휴대폰에서는 `http://(컴퓨터의 IP 주소):8080` 으로 접속할 수 있어요.

## 게임 소개

### GAME 01 — Kimchi Run (완성)

한국 시장 골목을 달리며 김치 재료를 모으고, 부엌에서 직접 양념을 버무려 김치를 완성해요.

- **모을 재료**: 배추 ×3, 무 ×2, 마늘 ×3, 고춧가루 ×2, 소금 ×2
- **제한 시간**: 60초 · **하트**: 3개
- **장애물**: 나무 상자, 옹기, 겹친 상자 (부딪히면 하트 -1, 잠깐 무적)
- **회복**: 하트가 줄었을 때 가끔 떠 있는 하트가 나와요.
- **김치 만들기**: 재료를 모두 모으면 부엌으로 이동 → ① 배추 절이기 → ② 양념 버무리기(빠르게 탭/SPACE) → ③ 양념 바르고 옹기에 담기 → 완성 축하 연출
- **문화 설명**: 결과 화면에서 김장 문화(2013년 유네스코 인류무형문화유산)를 소개해요.

| 조작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | ← → 또는 A D | ◀ ▶ 버튼 (누르고 있는 동안 이동) |
| 점프 / 2단 점프 | Space, ↑, W (공중에서 한 번 더) | JUMP 버튼 또는 게임 화면 탭 |
| 양념 섞기 | Space 연타 | MIX 버튼 또는 화면 탭 |
| 일시정지 | P 또는 Esc | 왼쪽 위 ⏸ 버튼 |

**점수 계산** (실제 플레이 결과로만 계산해요)

| 항목 | 계산 |
| --- | --- |
| 재료 점수 | 배추 100, 무 80, 마늘 60, 고춧가루 120, 소금 70 (필요 개수를 넘으면 절반) |
| 연속 수집 보너스 | 연속으로 모을 때마다 +10, +20 … 최대 +100. 부딪히거나 필요한 재료를 놓치면 끊겨요. |
| 버무리기 보너스 | 섞은 정도 × 250 (+ 100% 달성 시 100) |
| 남은 시간 보너스 | 남은 초 × 15 |
| 하트 보너스 | 남은 하트 × 150 |

완성하지 못하면 재료 점수와 연속 수집 보너스만 받아요.

**배지 5개**: 첫 김치, 무사고 달리기, 스피드 셰프(35초 이내), 콤보 수집가(×10), 완벽한 양념

### GAME 02~04 (준비 중)

- **Pavlova Dash** — 떨어지는 머랭·크림·과일을 받아 파블로바 완성
- **Palace Builder** — 기와·목재·장식을 모아 한국 전통 궁궐 전각 짓기
- **Kiwi Forest Rescue** — 날지 못하는 새 키위를 위한 숲속 서식지 만들기

## 공통 기능

- 메인 메뉴: 로고, 게임 카드 4개(직접 그린 SVG 그림), 설명, PLAY 버튼, 언어 변경, 소리 켜기/끄기, 플레이 기록
- 게임 화면: 점수, 남은 시간, 하트, 재료 수집 현황, 일시정지 / 계속하기 / 다시 하기 / 메인 메뉴
- 결과 화면: 점수 내역, 최고 기록(NEW BEST), 새 배지, 문화 설명, 다시 하기 / 메인 메뉴
- 기록 화면: 게임별 최고 점수, 플레이 횟수, 완성 횟수, 최단 완성 시간, 배지, 기록 초기화
- 전체 진행도: 완성한 게임 수 / 4, 획득 배지 수
- 저장: 브라우저 `localStorage` (이 기기에만 저장, 서버로 보내지 않음)
- 효과음: 외부 파일 없이 Web Audio API로 직접 합성
- 그래픽: 외부 이미지 없이 SVG와 Canvas로 직접 그림
- 다른 탭으로 가거나 앱을 내리면 자동으로 일시정지

## 프로젝트 구조

```
kiwi-kimchi-party/
├── index.html              시작 파일 (스크립트 순서가 정해져 있어요)
├── package.json            npm start / npm test 명령
├── README.md               이 문서
├── assets/images/icon.svg  브라우저 탭 아이콘
├── styles/
│   ├── main.css            메뉴, 기록, 버튼, 패널 등 공통 디자인
│   └── games.css           게임 화면(HUD, 터치 버튼, 결과 화면)
├── src/
│   ├── i18n.js             영어/한국어 문장
│   ├── save-manager.js     설정·기록·배지 저장
│   ├── audio.js            효과음 합성
│   ├── ui-manager.js       버튼, 아이콘, 확인 창 등 UI 도우미
│   ├── game-manager.js     게임 목록, 공통 HUD, 입력, 일시정지, 카운트다운, 결과 화면
│   ├── router.js           화면 전환 (#/menu, #/records, #/play/게임이름)
│   ├── main.js             시작점
│   ├── art/menu-art.js     메뉴용 SVG 그림 (로고 캐릭터, 게임 카드)
│   ├── screens/
│   │   ├── menu.js         메인 메뉴
│   │   └── records.js      플레이 기록
│   └── games/
│       └── kimchi-run.js   GAME 01 (그림, 규칙, 부엌 연출 모두 이 파일 안에)
└── tests/
    └── kimchi-run.e2e.js   실제 브라우저 자동 테스트
```

각 미니게임은 `src/games/` 안의 파일 하나로 독립되어 있고, `game-manager.js`가 넘겨주는 공통 기능(api)만 사용해요.
새 게임은 `KK.games.register({...})`로 등록하면 메뉴의 "Coming soon"이 자동으로 PLAY 버튼으로 바뀌어요.

## 테스트

```bash
cd kiwi-kimchi-party
npm test
```

Playwright와 Chromium이 필요해요 (`npm i -D playwright && npx playwright install chromium`).
테스트는 실제 브라우저로 메뉴, 언어/소리 변경, 기록 화면, Kimchi Run의 이동·점프·2단 점프·충돌·수집·점수·콤보·타이머·일시정지·다시 하기·김치 완성·게임 오버·시간 종료·메뉴 복귀, 그리고 휴대폰 세로/가로, 320px 작은 화면, 태블릿의 터치 조작과 화면 배치를 확인해요.
스크린샷은 `tests/screenshots/`에 저장돼요.

## 배포하기 (인터넷 주소로 공개)

이 게임은 정적 파일(HTML/CSS/JS)만 있어서 무료 정적 호스팅에 그대로 올리면 돼요.

### GitHub Pages

1. GitHub 저장소의 **Settings → Pages** 로 가요.
2. **Source**를 *Deploy from a branch*로 고르고, 배포할 브랜치와 `/ (root)` 폴더를 선택해 저장해요.
3. 몇 분 뒤 `https://(사용자이름).github.io/(저장소이름)/kiwi-kimchi-party/` 주소로 접속할 수 있어요.

### Netlify / Vercel / Cloudflare Pages

1. 사이트를 새로 만들고 이 저장소를 연결해요.
2. **Base(Root) directory**를 `kiwi-kimchi-party`로, **Build command**는 비워 두고, **Publish directory**는 `.`(또는 `kiwi-kimchi-party`)로 설정해요.
3. 배포 버튼을 누르면 주소가 생겨요. 빌드 과정은 필요 없어요.

## 멀티플레이 (아직 구현 전)

온라인 멀티플레이(방 만들기, 고유 방 코드, 대기실, 준비 상태, 방장 시작, 라운드 동기화, 순위, 연결 끊김 표시)는 **아직 만들지 않았어요.**
구현할 때는 Firebase Realtime Database 같은 실시간 서비스가 필요하고, 다음 설정이 필요해요.

1. Firebase 프로젝트 생성 → Realtime Database 만들기
2. 익명 로그인(Anonymous Auth) 켜기 — 개인정보 없이 임시 닉네임만 사용
3. 웹 앱 설정값(apiKey, projectId 등)을 설정 파일에 넣기
4. 보안 규칙: 플레이어는 자기 점수만 쓸 수 있고 다른 사람 점수는 바꿀 수 없게 설정
5. 점수 검증이 더 필요하면 Cloud Functions 같은 서버 측 검증 추가

이 설정이 끝나기 전에는 멀티플레이 기능이 동작하지 않아요.
