# THE DICE GENTLEMAN — 주사위 신사

심리 공포 주사위 도박 보스전. **단일 HTML 파일**(`index.html`)이며 외부 에셋이 없습니다.
브라우저로 `index.html`을 바로 열면 실행됩니다. 소리는 첫 클릭 후에 시작됩니다.

## 조작
| 입력 | 동작 |
|---|---|
| Space | 주사위 굴리기 / 승부 / 공격 타이밍 정지 |
| 1 / 2 / 3 | 재굴림 / 눈금 봉인 / 패배 무효 |
| Enter · 클릭 | 대사 넘기기 |
| 마우스 이동 · 방향키 · WASD | 회피 페이즈에서 금화 이동 |
| P · Esc | 일시정지 |
| M | 음소거 |

가상의 주사위와 가상의 점수만 사용하며 실제 돈·결제 기능은 없습니다.
회차 기록은 `localStorage`(`diceGentleman.save.v1`)에 저장됩니다.
