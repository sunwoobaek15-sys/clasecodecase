# TESTING — 수동 테스트 체크리스트

실기기(Android 8.0 / API 26 이상, 한국어 Google 음성 인식·TTS 설치) 기준입니다.
각 항목 옆에 결과를 적어 가며 진행하세요. `[ ]` → `[x]`.

## 0. 준비
- [ ] `adb install -r app-debug.apk` 설치 (CI 아티팩트 `jarvis-debug-apk` 또는 로컬 빌드)
- [ ] 설정(CONFIG) → NEURAL LINK 에 Anthropic API 키 입력 → `LINKED sk-ant-…` 표시
- [ ] IDENTITY 에 호칭 입력 (예: 민수) → 이후 답변에서 "민수님" 으로 부름
- [ ] 키를 잘못 입력 → 말 걸면 "API 키가 올바르지 않습니다" + 링 레드 글리치

## 1. 부팅 / 비주얼
- [ ] 첫 실행: 커서 깜빡임 → `INITIALIZING J.A.R.V.I.S. ...` 로그 스크롤 → 링이 바깥부터 하나씩 그려짐 → 플래시 + 진동 → 패널이 사방에서 들어옴 → 시간대 인사 TTS (3~4초)
- [ ] 설정 → BOOT SEQUENCE 끄기 → 재실행 시 바로 메인
- [ ] 대기 상태: 링 7겹이 서로 다른 방향/속도로 회전, 코어가 숨쉬듯 맥동
- [ ] 45초간 아무것도 안 하면 상태줄 `STANDBY // LOW POWER`, 회전 느려짐
- [ ] 폰을 기울이면 패널/배경 그리드가 시차 이동
- [ ] 테마 색 청록/앰버/레드/화이트 전환 → 전체 HUD 색 변경, 위젯 색도 갱신
- [ ] LITE MODE 켜기 → 입자/발광 감소, 부드러움 유지
- [ ] 화면 전환(하단 CORE/SCHEDULE/DATA/CONFIG): 패널 접힘 → 글리치 → 펼침

## 2. 음성 대화
- [ ] 코어 탭 → "띠링" + 진동, 링 가속, 마이크 음량에 반응하는 360° 스펙트럼, `LISTENING`
- [ ] 첫 사용 시 마이크 권한 이유 설명 HUD → AUTHORIZE → 시스템 권한 창
- [ ] 말하는 동안 로그 창에 `> USER · RECEIVING` 부분 인식 표시
- [ ] 생각 중: 링 역회전·고속, 데이터 조각이 코어로 빨려 들어감, `PROCESSING` 깜빡임, 저음 험
- [ ] 답변: `◆ JARVIS` 라벨과 함께 디코딩 타이핑 효과, TTS 낭독 중 코어가 음절 단위 펄스 + 원형 이퀄라이저
- [ ] 답변이 2~3문장 이내, 마크다운/이모지 없음, 호칭 사용
- [ ] 말하는 중 코어 탭 → 낭독 중단 후 바로 듣기
- [ ] 코어 길게 누르기 → 텍스트 입력창 → TRANSMIT
- [ ] 비행기 모드에서 질문 → "연결에 실패했습니다" + 레드 글리치 후 복귀
- [ ] 앱 재시작 후 "아까 뭐라고 했지?" → 이전 대화 문맥 유지 (Room 저장)

## 3. 일정 · 알람 · 메모 · 할 일
- [ ] "내일 아침 7시 반에 알람 맞춰줘" → `EXECUTING: ALARM SET` 카드 → 시계 앱에 알람 생성
- [ ] "평일 6시 알람" → 월~금 반복 알람
- [ ] "3분 타이머" → 시계 앱 타이머 시작
- [ ] "10분 뒤에 빨래 꺼내라고 알려줘" → 알림 권한 요청 → 10분 뒤 `◆ JARVIS 리마인더` 알림
- [ ] 리마인더 등록 후 재부팅 → 시각에 정상 알림 (BootReceiver)
- [ ] "오늘 일정 알려줘" → 캘린더 권한 요청 → 타임라인 카드 + 요약
- [ ] 캘린더 권한 거부 → "권한이 없어…" 안내 (도구는 권한 없음 tool_result)
- [ ] "금요일 오후 3시에 치과 일정 추가해" → 확인 다이얼로그(설정 기본값 ON) → 캘린더 앱에 생성
- [ ] "치과 일정 지워줘" → 일정 조회 후 삭제 시 **항상** 확인(레드 AUTHORIZATION REQUIRED), "아니요" → 취소됨
- [ ] "회의 메모: 다음 주 예산 확정 필요" → MEMO SAVED 카드 / DATA 화면 MEMOS 에 표시
- [ ] "예산 관련 메모 찾아줘" → 검색 결과
- [ ] "할 일에 보고서 작성 추가, 중요" → TASK QUEUED (PRIORITY: HIGH)
- [ ] "할 일 뭐 있어?" → 목록 카드
- [ ] "보고서 작성 완료" → 완료 처리
- [ ] DATA 화면에서 할 일 탭 → 스캔 라인이 지나가며 삭선, 길게 눌러 삭제
- [ ] SCHEDULE 화면: 24시간 다이얼에 일정이 호로 표시, 현재 시각 바늘, 날짜 ◀ ▶

## 4. 날씨 · 뉴스 · 브리핑
- [ ] "날씨 어때?" → 위치 권한 요청 → 날씨 카드(선 애니메이션 아이콘, 12시간 기온 그래프, 강수 막대)
- [ ] 위치 권한 거부 후 "부산 날씨" → 도시 지오코딩으로 정상
- [ ] 우상단 날씨 패널 / 강수확률 미니 그래프 표시
- [ ] "IT 뉴스 알려줘" → 뉴스 카드, 항목 탭 → 브라우저로 기사
- [ ] 하단 뉴스 티커가 전광판처럼 흐름
- [ ] 설정 → 브리핑 시각을 2~3분 뒤로 → HUD 스타일 알림(잠금화면 포함) → 탭 → 음성 브리핑 + 카드
- [ ] "아침 브리핑 해줘" → 즉시 브리핑

## 5. 폰 제어
- [ ] "유튜브 켜줘" / "카톡 열어" → 앱 실행
- [ ] "엄마한테 전화해" → 연락처·전화 권한 → **확인 다이얼로그 + 음성으로 "네"** → 발신
- [ ] "엄마한테 늦는다고 문자 보내" → 확인 → "아니요" → 미발송 / "네" → 발송
- [ ] 확인 다이얼로그 60초 무응답 → 자동 취소
- [ ] "손전등 켜" / "꺼" → 토치 on/off
- [ ] "볼륨 30으로" → 미디어 볼륨 30%
- [ ] "naver.com 열어줘" → 확인(설정 기본 ON) → 브라우저
- [ ] "강아지 산책 시간 검색해줘" → 검색 결과 브라우저
- [ ] "배터리 얼마나 남았어?" → 잔량/충전 상태 응답, 우하단 게이지 실제 값과 일치
- [ ] "지금 몇 시야?" → 현재 시각

## 6. 호출 진입점
- [ ] 홈 위젯 추가: 미니 리액터 + 시계 + 다음 일정, 탭 → 바로 듣기
- [ ] 빠른 설정 타일 "자비스" 추가 → 탭 → 바로 듣기
- [ ] 설정 → SET AS DEFAULT ASSISTANT → 디지털 어시스턴트 앱을 JARVIS 로 → 홈 버튼 길게 누르기 → 듣기 모드
- [ ] 호출 대기 모드 켜기 → 모델 다운로드 진행률 → `READY · LISTENING`, 상태바 상시 알림
- [ ] 앱 화면에서 "자비스" → 바로 듣기
- [ ] 앱을 닫은 상태에서 "자비스" → (다른 앱 위에 표시 권한 있으면) 앱이 열리며 듣기 / (없으면) 헤드업 알림
- [ ] 알림의 "호출 대기 끄기" → 서비스 종료

## 7. 설정
- [ ] TTS 속도/음높이 슬라이더 → TEST VOICE 로 확인
- [ ] 효과음 끄기 / 볼륨 조절, 진동 끄기
- [ ] AUTHORIZATION MATRIX: 일반 도구 토글 가능, 전화/문자/일정 삭제는 잠김(항상 ON)
- [ ] ACCESS CONTROL: 권한별 상태 표시, GRANT 로 요청
- [ ] 정확한 알람 권한 GRANT (Android 12+)
- [ ] PURGE CONVERSATION LOG → 로그 비워지고 문맥 초기화
