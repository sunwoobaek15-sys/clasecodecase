# 오늘도 꽝 🎣

> 휴가 왔는데 낚싯대밖에 안 챙겼다.

하와이에서 알로하 셔츠 입고 낚시하는 **2D 힐링 병맛 낚시 게임** 프로토타입입니다. (Unity 6 LTS · 2D URP · New Input System · 1920×1080)
5~10분 만에 "한 판만 더"가 나오도록, 던지기 → 입질 → 챔질 → 릴 미니게임 → 결과 카드가 짧고 빠르게 돕니다.

외부 에셋은 하나도 없습니다. 스프라이트는 전부 코드로 그리고(SDF 래스터라이저), 사운드는 빈 AudioSource 슬롯만 있습니다.
그래서 **폴더를 열고 ▶ Play만 누르면 바로 낚시**할 수 있고, 아트와 사운드는 나중에 슬롯에 끼우기만 하면 바뀝니다.

---

## 1. 바로 실행하기

1. **Unity Hub → Add → `OneulDoKkwang` 폴더**를 고릅니다.
   - 프로젝트 버전은 `6000.0.69f1`(Unity 6 LTS)입니다. 다른 6000.x 버전이 설치돼 있으면 Hub에서 그 버전을 골라 열어도 됩니다.
2. 처음 열면 **자동 셋업**이 돕니다. 데이터 에셋 34종, `Main` 씬, 빌드 설정, URP 2D 렌더러를 만들고 `Main` 씬을 엽니다.
   - Console에 `[오늘도 꽝] 셋업 완료!`가 보이면 끝입니다.
   - 안 보이면 메뉴 **Tools → Setup Fishing Scene**을 한 번 누르세요. 여러 번 눌러도 안전합니다. 이미 있는 에셋은 덮어쓰지 않습니다.
3. **▶ Play.**

> 셋업 없이 아무 빈 씬에서 Play를 눌러도 됩니다. 씬에 `GameBootstrap`이 없으면 자동으로 만들고, 데이터 에셋이 없으면 코드 기본값으로 시작합니다.

## 2. 조작

| 상황 | 마우스 / 터치 | 키보드 |
|---|---|---|
| 던지기 | **누르고 있으면** 파워 게이지가 오르내림 → **떼면 던짐**. 맨 위 노란 구간이면 **퍼펙트** | `Space` 누르고 떼기 |
| 입질 (찌가 흔들리고 `!`) | **0.6초 안에 탭**. 0.18초 안이면 "칼챔질" (릴 시작 게이지 +10%) | `Space` |
| 릴 미니게임 | **누르고 있으면** 초록 바가 오르고, 떼면 내려옴. 물고기와 겹치면 진행도가 차서 100%면 성공, 0%면 실패 | `Space` 누르고 있기 |
| 결과 카드 | 아무 데나 탭 / "한 번 더!" 버튼 | `Space` / `Esc` |
| 메뉴 | 화면 위 **도감 · 상점 · 이동 · 설정** 버튼 | `E` 도감 · `Q` 상점 · `M` 이동 · `F1` 설정(개발자 도구) · `Esc` 닫기 / 던지기 취소 |

## 3. 게임 흐름

- **인트로**: 알로하 셔츠 차림의 주인공이 하와이에 도착합니다. "휴가 왔는데 낚싯대밖에 안 챙겼다." 탭하면 넘어가고, 설정에서 다시 볼 수 있습니다.
- **상태 머신**: `Idle → Charging → Casting → Waiting → Bite → Reeling → Result`. 코드는 `FishingController`에 있습니다.
- **출현 확률** = 장소 × 시간대 × 날씨 × 미끼. 여기에 요일, 낚싯대 운, 던진 거리, 퍼펙트 여부가 곱해집니다 (`CatchTable`).
- **게임 시계**: 현실 1분이 게임 1시간이고, 금요일 15:00에 시작합니다. 낮은 06–17시, 노을은 17–20시(주황 → 분홍 → 보라), 밤은 20–06시입니다. 요일도 흐르기 때문에 월요일 규칙이 있습니다.
- **날씨**: 맑음과 비. 매 시간 13% 확률로 비가 와서 2~5시간 이어집니다. 비가 오면 해파리·장어·무지개 송어가 자주 나오고, "???"는 비 오는 밤에 황금 미끼를 끼워야만 나옵니다.
- **돈 → 상점**: 기본 장비 말고 낚싯대 4종, 미끼 5종, 장소 3곳을 살 수 있습니다. 연속으로 성공하면 판매가 보너스가 붙습니다 (최대 +50%).
- **고양이 NPC** (화관 쓴 고양이):
  - 실패하면 위로합니다. ("냥… 다음엔 될 거다냥")
  - 전설을 잡으면 깜짝 놀랍니다.
  - 시간대나 날씨가 바뀌면 한마디 합니다.
- **방치하면**: 18초가 지나면 주인공이 졸고, 26초가 지나면 고양이가 양동이에서 물고기를 훔쳐 갑니다. 미안하다고 조개를 두고 가기도 합니다.
- **연출**:
  - 찌가 떨어지면 물보라와 물결 링이 생기고, 입질 때는 찌가 흔들립니다.
  - 결과 카드는 팝업 트윈으로 뜨고 아이콘이 흔들립니다. 희귀 이상은 뒤에서 햇살이 돕니다.
  - 전설과 ???는 0.3배 슬로모, 화면 흔들림, 줌, 플래시, 비네트, 배너가 함께 나옵니다.
- **병맛 대사**: 160줄을 35개 카테고리로 나눴고, 셔플 백으로 고르게 나옵니다. 결과 카드 한 줄, 실패, 고양이 대사가 모두 이 대사를 씁니다. 여기에 어종마다 설명, 도망 대사, 챔질 외침이 따로 있습니다.

## 4. 폴더 구조

```
OneulDoKkwang/
├─ Assets/_Project/
│  ├─ Scripts/
│  │  ├─ Core/      진입점(GameBootstrap), 게임 상태·돈·장비(GameManager), 시계, 날씨, 오디오, JSON 저장, 트윈, 입력 브리지
│  │  ├─ Fishing/   상태 머신(FishingController), 던지기, 입질, 확률표(CatchTable), 릴 미니게임(ReelModel/FishMotion), 찌, 낚싯줄
│  │  ├─ Data/      ScriptableObject 정의(CatchData/RodData/BaitData/LocationData/GameDatabase/ArtLibrary), 기본 콘텐츠, 병맛 대사
│  │  ├─ UI/        HUD, 파워 게이지, 결과 카드, 도감, 상점, 설정, 인트로, 말풍선, 배너/토스트 (uGUI를 코드로 조립)
│  │  ├─ NPC/       주인공, 고양이, 양동이, 훌라 댄서
│  │  ├─ World/     배경 빌더, 하늘 그라데이션, 사인파 물결, 패럴랙스, 해/달, 비, 파티클, 카메라
│  │  └─ Art/       코드로 그리는 스프라이트 (SDF 래스터라이저 + 아이콘/캐릭터/배경/UI 페인터)
│  ├─ Editor/       Tools/Setup Fishing Scene, 첫 실행 자동 셋업, 어종 출현 검증
│  ├─ Data/         Catches/ Rods/ Baits/ Locations/ ArtLibrary.asset   ← 셋업이 생성
│  ├─ Resources/    GameDatabase.asset                                   ← 셋업이 생성
│  ├─ Scenes/       Main.unity                                           ← 셋업이 생성
│  ├─ Art/          SpriteUnlit.mat                                      ← 셋업이 생성
│  └─ Settings/     URP 2D 에셋                                          ← 셋업이 생성
├─ Packages/manifest.json   (URP 17.0.4, Input System 1.11.2, uGUI 2.0.0)
└─ ProjectSettings/         (버전, 1920×1080, Linear, Input System 활성화)
```

데이터 에셋은 직접 쓴 YAML이 아니라 **에디터 스크립트가 만듭니다** (`DefaultContent.cs` → `.asset`). GUID가 꼬이지 않게 하려는 선택입니다.

## 5. 바꾸고 싶을 때

### 밸런스 / 데이터
- `Assets/_Project/Data/Catches/*.asset`를 인스펙터에서 고치면 바로 반영됩니다. 출현 장소·시간·날씨, 크기, 가격, 릴 패턴, 난이도, 설명을 바꿀 수 있습니다.
- 어종을 추가하려면 `Data/Catches`에서 **Create → 오늘도 꽝 → Catch Data**로 만들고 **Tools → Setup Fishing Scene**을 다시 누르세요. 데이터베이스에 자동으로 들어갑니다.
  - `id`는 세이브와 도감의 키입니다. 영문으로 겹치지 않게 적으세요. 비었거나 다른 에셋과 겹치면 셋업이 파일 이름으로 바꿉니다.
  - 새 에셋의 기본 출현 조건은 "해변 · 하루 종일"입니다. 장소와 시간 칸을 원하는 대로 바꾸세요.
- **Tools → 오늘도 꽝 → 어종 출현 검증**은 모든 어종이 어떤 조건에서든 잡히는지, 가장 잘 나오는 조건과 확률이 얼마인지 Console에 표로 보여 줍니다.
- 기본값으로 되돌리려면 **Tools → 오늘도 꽝 → 데이터 에셋 강제 재생성**을 누르세요.
- 낚시 손맛 값은 `CastController.cs`(충전 속도, 퍼펙트 구간)와 `BiteSystem.cs`(챔질 0.6초, 입질 대기 시간)의 필드 기본값입니다.
  - Play 중에 `GameRoot/Fishing` 오브젝트에서 바로 바꿔 볼 수 있습니다. Play를 멈추면 원래대로 돌아오니, 마음에 드는 값은 코드에 옮기세요.

### 아트 교체 (스프라이트만 끼우면 됨)
| 바꿀 것 | 넣을 곳 |

## 6. 저장

- **JSON 파일**로 저장합니다 (PlayerPrefs 아님): `Application.persistentDataPath/oneuldo_kkwang_save.json`
  - Windows: `%USERPROFILE%\AppData\LocalLow\OneulDoKkwang\OneulDoKkwang\`
  - macOS: `~/Library/Application Support/OneulDoKkwang/OneulDoKkwang/`
- 저장하는 것: 돈, 도감(잡은 어종, 마리 수, 최고 크기), 장비와 보유 목록, 해금 장소와 현재 장소, 게임 시각과 날씨, 볼륨, 통계, 인트로 본 여부.
- 저장하는 때:
  - 물고기를 잡았을 때와 돈·장비가 바뀌었을 때
  - 20초마다 자동으로
  - 앱을 끄거나 백그라운드로 보낼 때
- 임시 파일에 먼저 쓴 다음 교체합니다. 파일이 깨졌으면 `.corrupt`로 백업하고 새로 시작합니다.
- 관리 메뉴: **Tools → 오늘도 꽝 → 세이브 파일 위치 열기 / 세이브 삭제**. 게임 안에서는 **설정 → 저장 초기화**를 두 번 누르면 됩니다.

## 8. 렌더링 메모

- 자동 셋업은 렌더 파이프라인이 비어 있을 때만 **URP 에셋(2D Renderer)** 을 만들어 적용합니다 (`Assets/_Project/Settings/`). 메뉴로 하려면 **Tools → 오늘도 꽝 → URP 2D 렌더러 만들고 적용**을 누르세요.
- 모든 스프라이트·메시는 언릿 `Sprites/Default` 머티리얼을 씁니다. 그래서 URP 2D든 Built-in이든 똑같이 보입니다.
  - 낮/노을/밤은 2D 라이트가 아니라 색 틴트로 바꿉니다. 하늘 그라데이션, 물 색, 원경/근경/구름 틴트가 따로 움직입니다.
- 물결은 스크립트입니다. 사인파 두 개를 겹치고, 찌가 떨어지면 물결 링이 퍼집니다. 셰이더 의존이 없습니다.
- 한글 폰트를 찾는 순서:
  1. `ArtLibrary.uiFont`
  2. OS 한글 폰트 (맑은 고딕, Apple SD Gothic Neo, Noto Sans CJK 등)
  3. Unity 기본 폰트

## 10. 검증 범위

이 프로젝트를 만든 환경에서는 **Unity 에디터를 직접 실행할 수 없었습니다.** 대신 아래를 확인했습니다.

- **컴파일**: 4가지 구성에서 C# 컴파일 오류 0, 경고 0. Unity 엔진·에디터·uGUI 참조 어셈블리와 Input System API 시그니처를 대상으로 Roslyn으로 확인했습니다.
  - 런타임(에디터·새 Input System)
  - 플레이어(새 Input System)
  - 플레이어(레거시 Input)
  - 에디터 스크립트
- **로직 테스트** (Unity 밖에서 실행):
  - 34종 모두 어떤 조건에서든 출현함
  - 월요일 규칙과 ??? 규칙
  - 확률 분포, 가격, 저장 데이터 정리
  - 릴 미니게임 봇 시뮬레이션 (어종별 성공률과 소요 시간)
- **그림**: 코드로 그린 아이콘 34종, 캐릭터, 4개 장소의 낮/노을/밤 배경을 PNG로 렌더링해서 눈으로 확인했습니다.
