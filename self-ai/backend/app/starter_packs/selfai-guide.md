# SELF AI 사용 가이드
> SELF AI 자신의 기능과 쓰는 법. 이 자료를 불러오면 AI가 SELF AI에 대한 질문에 답할 수 있습니다.

## SELF AI란 무엇인가
SELF AI는 내 컴퓨터에서 돌아가는 개인 AI 웹앱입니다. 대화하고, 중요한 정보를 기억하고, 자료를 지식으로 쌓고, 주제를 조사하고, 자기 답변을 평가합니다. 데이터는 모두 내 컴퓨터의 SQLite 파일(backend/data 폴더)에 저장됩니다. AI 모델은 기본적으로 내 컴퓨터의 Ollama가 돌리며, 클라우드 AI와 외부 네트워크는 기본으로 꺼져 있습니다.

## 기억(Memory)은 어떻게 저장되나
대화에서 "내 이름은 …", "나는 …를 좋아해", "기억해줘: …" 같은 말을 하면 기억으로 저장됩니다. 기억은 사용자 정보, 사용자 선호, 프로젝트 정보, 대화 기록, 학습한 지식, 중요한 결정의 6종류입니다. 같은 내용은 중복 저장하지 않고 횟수만 늘립니다. Memory 메뉴에서 직접 보고, 고치고, 지울 수 있습니다. 대화에서 자동 저장하는 기능은 Settings에서 끌 수 있습니다.

## 학습(Learning)과 지식(Knowledge)의 차이
Learning에 글이나 파일(txt, md, csv, json, html, pdf, docx)을 넣으면 핵심을 뽑고, 조각으로 나누고, 이미 있는 지식과 비교해 중복은 버리고 새 내용만 Knowledge에 저장합니다. 이것은 AI 모델 자체를 다시 훈련하는 것이 아닙니다. 저장된 지식은 대화할 때 검색되어 답변의 근거로 쓰입니다. 모델이 바뀌어도 지식은 그대로 남습니다.

## 조사(Research) 사용법과 한계
Research는 주제를 넣으면 계획을 세우고, 검색해서 출처를 모으고, 출처별 신뢰도를 매기고, 출처를 단 보고서를 만듭니다. 웹 검색은 기본으로 꺼져 있어서 Settings에서 외부 네트워크를 허용하고 검색 제공자(Wikipedia는 키가 필요 없음)를 골라야 합니다. 연결되지 않으면 "연결 필요"로 표시되고, 저장된 지식만으로 조사하는 선택도 있습니다. 신뢰도 점수는 도메인 종류와 출처 간 일치로 계산한 어림값이며 사실을 보장하지 않습니다.

## 자기 평가의 의미
답변마다 AI가 정확성, 논리성, 근거, 관련성을 1~5점으로 매깁니다. 같은 모델이 매긴 점수라 정답이 아니며, 사용자의 평점이나 수정 답변과 비교해서 봐야 합니다. 평가가 쌓인다고 모델이 저절로 똑똑해지지는 않습니다. 답을 좋게 만드는 실제 방법은 좋은 자료를 Learning에 넣는 것, 틀린 답을 직접 고쳐서 지식으로 저장하는 것, 더 큰 모델을 쓰는 것입니다.

## 모델 고르기와 속도
기본 모델은 qwen2.5:3b이고 RAM 8GB 컴퓨터에서 동작합니다. 답이 너무 느리면 qwen2.5:1.5b로 바꾸거나 Settings에서 "답변 자기 평가"를 꺼서 답변마다 생기는 추가 AI 호출을 줄입니다. RAM이 16GB 이상이면 qwen2.5:7b 같은 더 큰 모델이 더 정확합니다. 모델은 Settings의 "모델 받기"에서 터미널 없이 받을 수 있습니다.

## 개인정보와 데이터 위치
모든 데이터는 이 컴퓨터의 backend/data 폴더에 있습니다. 개인 기억과 지식은 클라우드 AI에 기본으로 보내지 않습니다. Settings에서 백업을 만들고, 백업에서 복구하고, JSON으로 내보낼 수 있습니다. 대량 삭제는 확인 문구를 입력해야 하고 실행 전에 자동 백업합니다.

## 휴대폰에서 쓰기
핸드폰에서 직접 실행하는 것은 안 되고, 컴퓨터에서 실행한 SELF AI에 같은 Wi-Fi의 핸드폰 브라우저로 접속합니다. backend/.env에 ACCESS_TOKEN을 정해 두고 --lan 옵션으로 실행하면 접속 주소가 표시되며, 핸드폰 Settings에 같은 토큰을 입력합니다. 컴퓨터가 켜져 있어야 합니다.
