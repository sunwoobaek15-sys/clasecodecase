# 에셋 분석 및 목록 (첨부 이미지 6장)

원본은 수정하지 않고 `art_source/original/`에 보존했습니다(`SHA256SUMS`로 무결성 확인 가능).
분석은 연결 요소(connected component) 검출 + 눈금자 오버레이 육안 확인으로 진행했고,
프레임 좌표는 `tools/sprite_defs.py`에 기록되어 있습니다.

추가로 발견한 문제와 처리(`tools/clean_sheets.py`):

- 1~5번은 투명 픽셀의 RGB에 원래 배경색(어두운 남색·녹색 글로우)이 남아 있고, 알파 1~23의 옅은 안개가 퍼져 있음 → 알파 24 미만 제거, 투명 픽셀 RGB 0으로 정리.
- 라벨은 알파 마스크에 포함된 불투명 박스라 그대로 두면 스프라이트에 섞임 → 라벨 색(2·4번 RGB≈30,36,41 / 5번 RGB≈15,23,55) + 사각형 형태로 자동 검출, 스프라이트와 붙은 5개는 대략 위치 힌트로 보정. 총 29개 제거, 인접 스프라이트 손상 없음(미리보기로 확인).
- 6번은 테두리에서 시작하는 플러드 필로 체크무늬를 제거하고, 시계 안쪽처럼 닫힌 영역은 "두 체크 색이 교차하는지"로 판별해 제거(실제 흰 옷감은 보존). 글로우 경계는 체크 색과의 차이로 알파를 추정해 역합성.
  **남은 문제:** 푸른 글로우 가장자리에 흰 잔여 픽셀이 일부 남아 있어 Phase 4에서 수작업 보정 필요.
- 원본은 AI 생성 "픽셀 풍" 이미지로 픽셀 격자가 맞지 않고 경계가 부드러움(아트 픽셀 ≈ 2.5~3px, PSNR 곡선에 뚜렷한 격자 없음).

## 2. 픽셀 크기 통일 방식

원본 시트는 캐릭터마다 그려진 크기가 같지만(주인공·베르단 모두 프레임 높이 ≈145px) 게임 속 크기는 달라야 합니다.
그대로 쓰면 픽셀 크기가 서로 달라지므로 다음 원칙으로 조정했습니다.

- 게임 해상도 640×360(가로는 기기 비율에 맞춰 확장), **모든 스프라이트를 런타임 확대·축소 없이 1:1로 표시** → 화면에서 모든 픽셀이 같은 크기.
- 원하는 게임 내 크기에 맞춰 파이프라인에서 축소 배율을 정함:
  주인공 0.44(≈64px), 슬라임 0.40(≈34px), 소형 슬라임 0.28, 강화형 0.31, 베르단 0.90(≈130px), 보스 이펙트 0.45, 뿌리 가시 0.34.
- 축소는 시트 전체를 같은 격자로 축소(프레임 간 서브픽셀 떨림 없음) → 알파 50% 기준 이진화 → 캐릭터별 공유 팔레트(프레임 간 색 깜빡임 없음) → 1px 어두운 외곽선(배경 대비 확보).
- 보스를 "2배 뚱뚱한 픽셀"로 확대하는 방식도 비교했으나 디테일이 뭉개져 채택하지 않음.
- 자동 테스트 `test_sprites_render_one_to_one`가 씬의 스프라이트 배율이 1인지 검사.
